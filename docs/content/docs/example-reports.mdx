Reports in the style of the IBCS® chart and table templates, built entirely
from `ibcs-react` components - no wrapper library, no post-processing, just the
props shown alongside each one.

Each report follows the same reporting pattern: the **message** first (the
takeaway is the headline, not a neutral label), then **who / what / when**, then
the exhibit. Data is realistic but fictitious, and company names are invented.
