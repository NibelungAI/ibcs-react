import { VarianceColumnChart } from "ibcs-react";

**ibcs-react** is a zero-dependency React charting library for business
communication in the IBCS® notation - the basis of ISO 24896. Variance
columns, waterfalls, statement tables, small multiples, dashboards and whole
reports: printable, self-explanatory, and consistent by construction.

```tsx
import { VarianceColumnChart } from "ibcs-react";

<VarianceColumnChart data={[{ category: "Q1", AC: 92.1, PY: 86.7 }]} width={640} height={320} />;
```
