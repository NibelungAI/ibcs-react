import { AreaChart } from "ibcs-react";

A single scenario filled from zero, with a second scenario drawn over it as a
reference line. Because the fill starts at zero, the area is only honest for
measures where zero is meaningful.

## When to use

A continuous magnitude over time — cash position, headcount, backlog — where
the filled area communicates level.

```tsx
<AreaChart data={months} baseline={null} />  // area only
```

To show the running over/under-performance against a benchmark rather than the
level, use [VarianceAreaChart](/docs/components/variance-area).
