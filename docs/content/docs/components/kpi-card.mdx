import { KpiCard } from "ibcs-react";

A single headline number with one or more IBCS impact-coloured deltas — the
colour follows favorability, not the sign — and an optional sparkline under the
figure. Built to drop into a report grid as a `kpi` block.

## When to use

A single KPI in a dashboard strip — revenue, margin, headcount — with its
variance and trend at a glance.

## Example

<Frame center>
  <div style={{ width: 240 }}>
    <KpiCard
      label="Revenue"
      values={{ AC: 30.1e6, PY: 25.6e6, PL: 28.5e6 }}

import { KpiCard } from "ibcs-react";

/>;

## More examples

### A cost KPI (higherIsBetter = false)

For costs, an increase is unfavorable. Setting `higherIsBetter={false}` flips
the impact colouring, so the +1.3M rise reads red even though the number went
up.

<Frame center>
  <div style={{ display: "flex", gap: 16, flexWrap: "wrap" }}>
    <div style={{ width: 220 }}>
      <KpiCard
        label="Revenue"
        values={{ AC: 30.1e6, PY: 25.6e6 }}
        comparisons={["PY"]}
        format={{ compact: true, decimals: 1 }}
      />
    </div>
    <div style={{ width: 220 }}>
      <KpiCard
        label="Operating cost"
        values={{ AC: 9.7e6, PY: 8.4e6 }}
        comparisons={["PY"]}
        higherIsBetter={false}
        format={{ compact: true, decimals: 1 }}
      />
    </div>
  </div>
</Frame>

```tsx
// Revenue up -> green (favorable)
<KpiCard label="Revenue" values={{ AC: 30.1e6, PY: 25.6e6 }} comparisons={["PY"]} />

// Cost up -> red, because higher is worse
<KpiCard
  label="Operating cost"
  values={{ AC: 9.7e6, PY: 8.4e6 }}
  comparisons={["PY"]}
  higherIsBetter={false}
/>
```

### Units live in `format`

There is no `unit` prop. The unit is part of `format`: `currency` for a leading
symbol (`{ currency: "€" }` renders €30.1M), `suffix` for a trailing one
(`{ suffix: "%" }` renders 18.4%). The card states the unit once, muted, beside
the headline instead of repeating it on every delta.

<Frame center>
  <div style={{ display: "flex", gap: 16, flexWrap: "wrap" }}>
    <div style={{ width: 220 }}>
      <KpiCard
        label="Revenue"
        values={{ AC: 30.1e6, PY: 25.6e6 }}
        comparisons={["PY"]}
        format={{ currency: "€", compact: true, decimals: 1 }}
      />
    </div>
    <div style={{ width: 220 }}>
      <KpiCard
        label="Gross margin"
        values={{ AC: 18.4, PY: 17.1 }}
        comparisons={["PY"]}
        format={{ suffix: "%", compact: false, decimals: 1 }}
      />
    </div>
  </div>
</Frame>

```tsx
<KpiCard label="Revenue" values={{ AC: 30.1e6, PY: 25.6e6 }} format={{ currency: "€" }} />
<KpiCard
  label="Gross margin"
  values={{ AC: 18.4, PY: 17.1 }}
  format={{ suffix: "%", compact: false, decimals: 1 }}
/>
```

Set `animate={false}` to render the headline outright — no frame loop, no
re-renders — which is what you want in tests, print and SSR-heavy pages.
Users with `prefers-reduced-motion` set never see the count-up either way:
the default consults the OS preference and renders the final value
immediately, and SSR always emits the finished figure.

## Ratio measures: percentage-point deltas

A percentage MEASURE — a margin, a rate, a share — moves in percentage
points. Declare it with `unit="ratio"` and the delta renders as `+0.6pp`,
while the relative delta is dropped: "+0.9%" beside "18.4%" invites reading
a relative change as points, the exact confusion ISO 24896 separates the two
notations to prevent.

<Frame center>
  <div
    style={{
      display: "grid",
      gridTemplateColumns: "repeat(auto-fit, minmax(190px, 1fr))",
      gap: 12,
      width: "100%",
      maxWidth: 460,
    }}
  >
    <KpiCard
      label="EBIT margin"
      values={{ AC: 18.4, PY: 17.1 }}
      unit="ratio"
      format={{ suffix: "%", compact: false, decimals: 1 }}
    />
    <KpiCard
      label="Churn rate"
      values={{ AC: 3.1, PY: 3.4 }}
      unit="ratio"
      higherIsBetter={false}
      format={{ suffix: "%", compact: false, decimals: 1 }}
    />
  </div>
</Frame>

```tsx
<KpiCard
  label="EBIT margin"
  values={{ AC: 18.4, PY: 17.1 }}
  unit="ratio" // deltas in percentage points: +1.3pp, no relative %
  format={{ suffix: "%", compact: false, decimals: 1 }}
/>
```

The linter pairs with it: `checkIbcs` emits a `ratio-units` info for a KPI
formatted with `suffix: "%"` that has not been declared a ratio.
