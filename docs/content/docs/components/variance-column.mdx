import { VarianceColumnChart } from "ibcs-react";

The workhorse period comparison: solid AC columns over the comparison
scenario's own notation (PY solid grey, PL hollow frame, FC hatched), with an
absolute or percent variance panel underneath.

## When to use

Comparison / deviation across a few categories or periods - e.g. revenue by
quarter, AC vs PY.

## Example

<Frame center>
  <VarianceColumnChart
    title="Net sales - AC vs PY, mEUR"
    data={[
      { category: "Jan", AC: 30.1, PY: 28.6 },
      { category: "Feb", AC: 27.4, PY: 28.9 },
      { category: "Mar", AC: 32.2, PY: 29.4 },
      { category: "Apr", AC: 29.8, PY: 30.4 },
      { category: "May", AC: 33.1, PY: 30.1 },
    ]}
    width={620}
    height={320}
  />
</Frame>

```tsx
import { VarianceColumnChart } from "ibcs-react";

<VarianceColumnChart
  data={[
    { category: "Jan", AC: 30.1, PY: 28.6 },
    { category: "Feb", AC: 27.4, PY: 28.9 },
  ]}
  comparison="PY"
  variance="abs" // or "pct" / "none"
  mark="bar" // or "pin"
  width={620}
  height={320}
/>;
```

## More examples

### Relative variance as pins

last year, which the percent variance makes explicit.

## Error bars

A datum's `acError` stands a vertical error bar on its AC column, and
`absError` (or `pctError`, in percent units, with `variance="pct"`) one on its
variance bar - each on its own scale, which widens so the whisker fits. A value
label moves above its whisker. The intervals' text is in the tooltip and the
screen-reader table.

<Frame center>
  <VarianceColumnChart
    width={460}
    height={280}
    format={{ compact: false, fractionDigits: 1 }}
    labels={{ scenario: { AC: "new", PY: "old" } }}
    data={[
      { category: "Hunter", AC: 910.8, PY: 909.6, acError: 0.8, absError: 0.6 },
      { category: "Ret", AC: 890.5, PY: 892.9, acError: 1.2, absError: 0.9 },
      { category: "Fire", AC: 860.1, PY: 859.8, acError: 1.0, absError: 0.7 },
    ]}
  />
</Frame>

```tsx
<VarianceColumnChart
  format={{ compact: false, fractionDigits: 1 }}
  labels={{ scenario: { AC: "new", PY: "old" } }}
  data={[
    { category: "Hunter", AC: 910.8, PY: 909.6, acError: 0.8, absError: 0.6 },
    { category: "Fire", AC: 860.1, PY: 859.8, acError: 1.0, absError: 0.7 },
  ]}
/>
```

Fire's Δ of +0.3 ± 0.7 straddles zero - no measurable change - and the picture
says so.
