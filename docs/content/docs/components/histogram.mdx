import { HistogramChart } from "ibcs-react";
import { engineBins, fights, fightsHalfWidth, fightsMean } from "@/lib/demo-data/distribution";

A histogram counts values in classes of identical width (IBCS CH 1.3) and
draws each count as a column on a horizontal value axis - the exception IBCS
makes for statistical distributions (UN 3.4). It answers "how are the values
spread?": the results of 6,000 simulated fights, the response times of a
service, the margins of a product range.

## When to use

When the reader needs the shape of a distribution - where most values lie, how
far the tails reach - and not one number per category. For values over time,
use a line or column chart; to compare a few groups' ranges side by side, a
range per group reads faster than several histograms.

## Two ranges, never confused

A histogram of an estimate carries two ranges that answer different questions,
and the chart draws them so that one cannot be read for the other:

- **The mean's interval** - how well the average is known. It narrows as more
  values come in. It is drawn as an error bar above the columns, labelled "Mean
  911.3 ± 0.8 (95%)", with a line at the mean down to the top of the column it
  falls in and a tick under the axis: the line never crosses a column, so every
  class keeps one whole width. The chart never derives the interval: pass
  `mean` with the half-width you computed (for example 1.96 standard errors)
  and its `level`. An interval comes with its level or not at all, since "±
  0.8" alone reads like a standard deviation; a mean without one is written
  alone, "Mean 911.3".
- **The spread of the values** - how much a single value varies. It does not
  narrow with more values. It is drawn as a band behind the columns, with a
  bracket and its caption under the axis: "Middle half 890.1–932.2". By default
  it is the middle half of `values`, from the first to the third quartile; pass
  `spread` for a range of your own, with a `label` that names it, or `false`
  for none.

Each has its own mark (an error bar, a band), its own row (above the columns,
under the axis) and its own words.

## Classes of one width

`values` are binned by `computeHistogram` (also in `ibcs-react/core`):

- The number of classes follows the Freedman-Diaconis rule - a width of
  2 × IQR × n^(-1/3) - bounded to 20-60 classes (`binning.minBins`,
  `binning.maxBins`); `binning.bins` fixes it instead. For a few dozen values,
  lower `minBins`.
- Every class has the same width; the counts sum to n, the number of finite
  values (NaN and ±Infinity are left out); the first edge is the smallest value
  and the last edge is at or above the largest. Each class counts the values in
  [lower, upper); the last one also counts its upper edge.
- Values that are all equal make one class at that value.

An engine that bins its own results passes them as `bins` - a start, one width
and the counts - so a class of another width cannot even be written down:

<Frame center>
  <HistogramChart
    bins={engineBins}
    mean={{ value: 909.6, halfWidth: 0.7, level: 0.95 }}
    spread={{ from: 877.2, to: 942.4, label: "10th to 90th percentile {range}" }}
    scenario="FC"
    format={{ compact: false, fractionDigits: 1 }}
    width={640}
    height={260}
  />
</Frame>

```tsx
<HistogramChart
  bins={{ start: 850, width: 10, counts: [4, 19, 61, 152, 288, 401, 395, 301, 170, 72, 25, 6] }}
  mean={{ value: 909.6, halfWidth: 0.7, level: 0.95 }}
  spread={{ from: 877.2, to: 942.4, label: "10th to 90th percentile {range}" }}
  scenario="FC" // a forecast distribution: hatched
  format={{ compact: false, fractionDigits: 1 }}
/>
```

A spread that is not the middle half needs its own words: its `label`, a
template with `{range}`, wins over the `spread` word of `labels`.

## Labels instead of grid lines

There is no count axis and no grid line (IBCS SI 3.1). Each column's count is
written above it when every count fits above its column; otherwise only the
tallest column's count is, and the screen-reader table and the tooltip carry
all of them. The class edges are written at the two ends of the axis - the
last one left out when both do not fit, and either left out when the mean's
tick falls on it - and n on the title line. Every kind of label has a row of
its own, so none crosses another; the mean's line pauses at a count label it
would cross.

## Words, numbers and notation

The chart's words come from `labels` (or `IbcsThemeProvider`): `mean`
("Mean {value}"), `spread` ("Middle half {range}"), `sampleSize`
("n = {n}"), and the table's `count` and `share`. Values follow `format`'s
`fractionDigits` and `locale`; counts are whole numbers and shares percentages
(`percentFractionDigits`, default 1) in the same locale.

The class edges, the spread and the mean are written in full unless `format`
sets `compact: true`, since compact numbers would name neighbouring classes
alike ("1.3K–1.3K"). Without `fractionDigits` they take one decimal place past
the class width's first significant digit, so neighbouring edges never read
alike: classes 5 wide from 1,300 are "1,300.0–1,305.0", classes 20 wide
"1,300–1,320". A mean's interval then keeps two significant figures of its
half-width. With `compact: true` the values are compact, with as many digits as
keep neighbouring edges apart ("1.300K–1.305K" for classes 5 wide):

<Frame center>
  <HistogramChart
    title="DPS po borbi"
    values={fights}
    mean={{ value: fightsMean, halfWidth: fightsHalfWidth, level: 0.95 }}
    format={{ compact: false, locale: "sr-Latn", fractionDigits: 1 }}
    labels={{
      mean: "prosek {value}",
      spread: "srednja polovina borbi {range}",
      sampleSize: "{n} borbi",
      count: "Borbi",
      share: "Udeo",
    }}
    width={640}
    height={300}
  />
</Frame>

```tsx
<HistogramChart

  values={dpsPerFight}
  mean={{ value: mean, halfWidth: halfWidth, level: 0.95 }}

```

The columns wear their `scenario`'s IBCS notation: AC solid (the default), PY
grey, PL outlined, FC hatched.

## Accessibility

The svg is one labelled image, described as "Histogram of 6,000 values in 41
classes" (`ariaLabel` replaces that). Beside it, a visually hidden table lists every class - its range,
count and share - and its caption carries the mean, the spread and n in the
chart's own words.
