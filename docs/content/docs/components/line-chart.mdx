Scenario lines in IBCS notation with point markers, plus an optional variance
panel against a chosen base.

## When to use

Trend over many periods (10+, up to hundreds of points). Lines carry markers so
they read as connectors, not continuous values. Use columns instead for few
periods.

By default every scenario present in the data is drawn; narrow that with
`series={["AC", "PY"]}`. `showMarkers` forces the markers back on (or off)
when the automatic density rule picks the wrong side.

## Words and per-series digits

Each line's end label is its scenario's word and its last value, from the
template `labels.endLabel` ("{name} {value}"; `"{value}"` writes the value
alone). `labels.scenario` replaces the word; an empty one leaves that line's
value alone, while its screen-reader column falls back to the scenario's title
("PY") - a header never goes blank. `seriesFormat` gives a series its own number
format - its end label and its column of the screen-reader table - merged over
`format`, so it keeps the chart's `locale`; the variance panel keeps `format`:

```tsx
<LineChart
  data={data}
  labels={{ scenario: { AC: "DPS", PY: "" } }}
  format={{ compact: false, fractionDigits: 1 }}
  seriesFormat={{ AC: { compact: false, fractionDigits: 2 } }}
/>
```

See [Numbers and words](/docs/localization) for decimals, locales and the whole
word dictionary.

## Point callouts

`callouts` label the points you name - the inflection points of J.P.
Morgan's _Guide to the Markets_ (p. 4), each written with its date and value
beside its point; the gear changes in a run of results. A callout names a
period (`index`), optionally a `series` (default AC), and its text, with `"\n"`
for a new line:

<Frame center>
  <LineChart
    title="DPS across 20 runs"
    data={runs}
    format={{ compact: false, fractionDigits: 1 }}
    callouts={[
      { index: 4, label: "Run 5: T1 helm\n899.8" },
      { index: 11, label: "Run 12: Signet of Embers\n914.9" },
      { index: 18, label: "Run 19: the best set\n931.2" },
    ]}
    width={640}
    height={300}
  />
</Frame>

```tsx
<LineChart
  data={runs}
  callouts={[
    { index: 4, label: "Run 5: T1 helm\n899.8" },
    { index: 18, label: "Run 19: the best set\n931.2" },
  ]}
/>
```

Each point gets a dot, and its label a place clear of every line, marker,
end label, reference caption and other callout: right beside the point -
above a peak, below a trough (or the side `placement` names) - else moved
away with a leader. The plot keeps room above its highest point for the
labels. A callout that finds no room anywhere is numbered beside its point
and written under the chart, which grows by that list, so none is left out;
when even its number has no place, its note names its period instead. The
screen-reader table carries each callout's text in its period's row
(`labels.note`, "Note").

## Fans

`fans` are bands whose edges vary from period to period - the 10th to the
90th percentile of all fights at every moment, say - drawn faint beneath the
lines, a later band over an earlier one. Each edge is a value per period,
aligned with `data`; a missing value breaks the band, as it breaks a line,
and the value axis grows to hold the bands. A band's `label` is placed beside
its right end like a callout, tied to the edge it names:

<Frame center>
  <LineChart
    title="DPS over one fight, against all fights"
    data={fightDps}
    fans={fightFans}
    format={{ compact: false, fractionDigits: 0 }}
    references={[{ axis: "x", kind: "band", from: 10, to: 15, label: "Rapid Fire" }]}
    width={640}
    height={300}
  />
</Frame>

```tsx
<LineChart
  data={dpsEvery3s} // { category: "0", AC: 1050 }, …
  fans={[
    { from: p10, to: p90, label: "10th to 90th percentile" }, // one value per period
    { from: q1, to: q3, label: "Middle half" },
  ]}
/>
```

The chart draws the edges it is given. Each band has its column in the
screen-reader table - its `label`, else `labels.band` ("Band {n}") - with
"from–to" per period.
