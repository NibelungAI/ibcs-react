import { RankingVarianceChart } from "ibcs-react";

Rows sorted by deviation: AC bars with the comparison overlaid, then the
absolute variance as bars, then the relative variance as pins - with a bold
total row underneath.

## When to use

Rank entities (regions, states, products) by their variance vs plan - see who
beats and who misses, with absolute and relative deviation side by side and a
bold total.

```tsx
import { RankingVarianceChart } from "ibcs-react";

<RankingVarianceChart
  title="Net sales by state - AC vs Plan"
  baseLabel="PL"
  sortBy="variance" // "variance" | "value" | "none"
  data={[
    { label: "California", AC: 188, base: 154 },
    { label: "Texas", AC: 197, base: 201 },
    { label: "Virginia", AC: 69, base: 166 },
  ]}
/>;
```

The relative panel is the reason small bases stay honest: a tiny entity can
double while contributing almost nothing in absolute terms. Percentages beyond
`clampPct` draw an off-scale arrow instead of stretching the whole scale for
one outlier.

`baseLabel` is what the headers say - set it to `"PY"` when the base values are
last year's.

## Error bars and a tied band

Each datum may carry the half-width of an interval for each mark: `acError`
on the AC bar, `absError` on the ΔPL bar (give the difference's own error - for
paired runs, the paired one; it is never derived from `acError`) and
`pctError` on the ΔPL% pin, in percent units. Each is drawn as an error bar on
its mark's own scale, and the shared scales widen so every whisker fits. With
`acError` the AC labels get a gutter of their own, sized for the widest one,
and each sits past its whisker's end; without it the layout is 1.4's. The
interval's text - "+3.46 ± 0.46" - is in the tooltip and the screen-reader
table; the printed labels stay the point values.

`bands` shades a value range across one panel's data rows - here the variants
statistically tied with the best, on the ΔPL panel. A band's `label` is printed
on a line above the panel headers - one label may use the whole line, several
share it by panel - and added to the screen-reader table's caption. On the ΔPL
and ΔPL% panels favorable points right, so for higher-is-better data a band's
values are plain Δ values.

```tsx
<RankingVarianceChart
  baseLabel="Equipped"
  format={{ compact: false, fractionDigits: 2 }}
  labels={{ scenario: { AC: "DPS" } }}
  bands={[{ panel: "abs", from: 2.9952, to: 3.9194, label: "Tied with the best" }]}

    { label: "Best set", AC: 914.3013, base: 910.8441, acError: 0.4682, absError: 0.4621 },
```

The AC panel's bars start at zero, so an interval of ±0.5 on 914 is a hair's
width there - that is the honest picture; the ΔPL panel is where it reads.
